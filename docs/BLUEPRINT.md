# LitePDF Blueprint (source of truth)

This file describes the target design. Code that differs from it is either a bug or needs this file updated in the same commit.
Status markers: **[built]** exists in code · **[planned]** see TASKS.md.

## 1. Scope

| Feature | Summary | Phase |
|---|---|---|
| Reading | Continuous vertical scroll; zoom (buttons, Ctrl+wheel, fit width/page); go to page; links; password PDFs | 1 |
| Thumbnails | Virtualized sidebar list; click to jump; current page selected | 2 |
| Chapters | Outline tree; click to jump; current chapter follows scroll | 2 |
| Text | Select (drag/double/triple click), Ctrl+C, copy page text, copy region/page as image, Ctrl+F search | 3 |
| OCR | Scanned-page detection, background OCR, region OCR, open/paste images, cached results | 4 |
| Annotations | Highlight/underline/strikeout (5 colors), sticky notes, panel, save, export | 5 |
| Comfort | Tabs, recent files + resume, dark/sepia, two-page view, rotate, full screen, bookmarks, read aloud, print | 6 |

Out of scope for v1: editing page content, form design, digital signing, cloud sync.

## 4. Threading model **[built]**

```
UI thread ──RunAsync(fn, priority, ct)──▶ PdfiumWorker (dedicated thread "PDFium")
    ▲                                        │ PriorityQueue<WorkItem, (priority, seq)>
    └──────── await Task<T> ◀────────────────┘ runs fn; honours ct before start
```
- `PdfiumWorker.Instance` is process-wide. `FPDF_InitLibrary` runs on that thread at startup.
- Every native handle (document, page, text page, bitmap) is created, used and destroyed **only** inside a work item.
- Priorities (lower runs first), defined in `RenderPriority`:

| Constant | Value | Used for |
|---|---|---|
| `Visible` | 0 | Pages in the viewport |
| `Interactive` | 10 | Outline, text for selection/copy |
| `Nearby` | 20 | Pre-render ±2 pages |
| `Thumbnail` | 30 | Sidebar thumbnails |
| `Background` | 40 | OCR renders, search indexing |

- Cancellation: a work item whose token is already cancelled when dequeued is skipped (Task → Canceled). A page scrolled out of view cancels its token.
- Results come back through `await`. The WPF `SynchronizationContext` resumes on the UI thread. `WriteableBitmap` is created on the UI thread from `RenderedBitmap.Pixels`.
- OCR (`WindowsOcrEngine`) runs on the thread pool. It is independent of PDFium, so only its render step goes through the worker.

## 5. Units and coordinates **[built in ViewMath]**

| Space | Unit | Origin | Where |
|---|---|---|---|
| PDF page | point = 1/72 in | bottom-left (PDFium page space) | Core, Pdfium, annotations, text boxes |
| Layout | DIP = 1/96 in | top-left of page | WPF layout |
| Device | pixel | top-left of bitmap | Render buffers, OCR |

- `PageSize` is in points, **with page /Rotate already applied** (as `FPDF_GetPageSizeByIndex` returns it).
- `dip = points * zoom * 96/72`
- `pixels = dip * dpiScale` (dpiScale from `VisualTreeHelper.GetDpi`)
- Render pixel size = `round(pageW * zoom * 96/72 * dpiScale)` × `round(pageH * ...)`
- Page point → bitmap pixel (no extra rotation):
  - `px = (x - 0) * sx`
  - `py = (pageH - y) * sy`
  - where `sx = bmpW / pageW` and `sy = bmpH / pageH`
  - For rotated pages, or pages whose MediaBox doesn't start at 0,0, use `FPDF_PageToDevice` / `FPDF_DeviceToPage` inside the worker. `PdfiumDocument.PageToDevice/DeviceToPage` **[planned T-30]** wraps them.
- PDFium text rects come as (left, top, right, bottom) in page space, with top > bottom.

## 6. Core contracts

```csharp
// Geometry.cs
public readonly record struct PageSize(double Width, double Height);          // points
public readonly record struct RectD(double Left, double Top, double Right, double Bottom);
public readonly record struct PointD(double X, double Y);

// Rendering.cs
public sealed record RenderedBitmap(int Width, int Height, int Stride, byte[] Pixels); // BGRA32, opaque
[Flags] public enum RenderFlags { None = 0, Annotations = 1, Grayscale = 8, Printing = 0x800 }
public static class RenderPriority { Visible=0, Interactive=10, Nearby=20, Thumbnail=30, Background=40 }

// Outline.cs
public sealed record OutlineItem(string Title, int PageIndex, IReadOnlyList<OutlineItem> Children); // PageIndex -1 = no target

// IPdfDocument.cs
public interface IPdfDocument : IAsyncDisposable
{
    string FilePath { get; }
    int PageCount { get; }
    IReadOnlyList<PageSize> PageSizes { get; }
    Task<RenderedBitmap> RenderPageAsync(int pageIndex, int pixelWidth, int pixelHeight,
        RenderFlags flags, int priority, CancellationToken ct = default);
    Task<IReadOnlyList<OutlineItem>> GetOutlineAsync(CancellationToken ct = default);
    Task<string> GetPageTextAsync(int pageIndex, CancellationToken ct = default);
    Task<int> GetCharCountAsync(int pageIndex, CancellationToken ct = default);   // 0 ⇒ likely scanned
    // [planned] T-30 Task<PageTextLayer> GetTextLayerAsync(int pageIndex, CancellationToken ct)
    // [planned] T-14 Task<IReadOnlyList<PdfLink>> GetLinksAsync(int pageIndex, CancellationToken ct)
    // [planned] T-50 annotations: Add/Remove/List + SaveAsync(string path, bool incremental)
}
// Open: PdfiumDocument.OpenAsync(string path, string? password, CancellationToken ct)
// Throws PdfiumException with ErrorCode: 1 Unknown, 2 File, 3 Format, 4 Password, 5 Security, 6 Page

// Ocr.cs
public interface IOcrEngine
{
    bool IsAvailable { get; }
    IReadOnlyList<string> AvailableLanguages { get; }  // BCP-47 tags, e.g. "en-US"
    int MaxImageDimension { get; }                       // Windows: 10000
    Task<OcrPageResult> RecognizeAsync(RenderedBitmap bitmap, string? languageTag, CancellationToken ct = default);
}
public sealed record OcrWord(string Text, RectD PixelRect);        // bitmap pixels, top-left origin (Top < Bottom)
public sealed record OcrLine(string Text, IReadOnlyList<OcrWord> Words);
public sealed record OcrPageResult(string LanguageTag, double? TextAngle, IReadOnlyList<OcrLine> Lines)
{ public string Text { get; } /* lines joined with \n */ }
```

### Planned text layer (T-30)
```csharp
public enum TextSource { Pdf, Ocr }
public readonly record struct TextGlyph(char Char, RectD Box);     // page points; Box empty for generated spaces/newlines
public sealed class PageTextLayer
{
    int PageIndex; TextSource Source; IReadOnlyList<TextGlyph> Glyphs;
    string GetText(int start, int count);
    int HitTest(PointD pagePoint, double tolerance);                // nearest glyph index or -1
    IReadOnlyList<RectD> GetLineRects(int start, int count);        // merged per line, for selection & highlight quads
}
```
- PDF source: `FPDFText_CountChars`, `FPDFText_GetUnicode`, `FPDFText_GetCharBox`.
- OCR source: each `OcrWord` becomes glyphs (box split evenly across chars), with a space glyph between words and `\n` between lines. Pixel → points: `x/sx`, `pageH - y/sy`.
- Selection, copy, search and highlight **must** use only `PageTextLayer`, so OCR text behaves exactly like PDF text.

## 7. PDFium API map

| Need | Functions |
|---|---|
| Init | `FPDF_InitLibrary` (worker thread) |
| Open | `FPDF_LoadCustomDocument(FPDF_FILEACCESS*, password)`, streaming from `FileStream` (Unicode paths, low memory); `FPDF_GetLastError` |
| Pages | `FPDF_GetPageCount`, `FPDF_GetPageSizeByIndex`, `FPDF_LoadPage`, `FPDF_ClosePage` |
| Render | `FPDFBitmap_Create(w,h,0)`, `FPDFBitmap_FillRect(…,0xFFFFFFFF)`, `FPDF_RenderPageBitmap(bmp,page,0,0,w,h,0,FPDF_ANNOT)`, `FPDFBitmap_GetBuffer/GetStride`, `FPDFBitmap_Destroy` |
| Outline | `FPDFBookmark_GetFirstChild/GetNextSibling/GetTitle/GetDest/GetAction`, `FPDFAction_GetDest`, `FPDFDest_GetDestPageIndex` (guard against cycles: max depth 32, max 10k items) |
| Text | `FPDFText_LoadPage/ClosePage/CountChars/GetText/GetUnicode/GetCharBox/GetCharIndexAtPos/CountRects/GetRect` |
| Search | `FPDFText_FindStart/FindNext/GetSchResultIndex/GetSchCount/FindClose` |
| Links | `FPDFLink_Enumerate`, `FPDFLink_GetDest/GetAction`, `FPDFAction_GetType/GetURIPath`, `FPDFLink_GetAnnotRect` |
| Annotations | `FPDFPage_CreateAnnot(FPDF_ANNOT_HIGHLIGHT=9 / UNDERLINE=10 / STRIKEOUT=12 / TEXT=1)`, `FPDFAnnot_AppendAttachmentPoints`, `FPDFAnnot_SetColor`, `FPDFAnnot_SetRect`, `FPDFAnnot_SetStringValue("Contents")`, `FPDFPage_GetAnnotCount/GetAnnot/RemoveAnnot`, `FPDFPage_CloseAnnot` |
| Save | `FPDF_SaveAsCopy(doc, FPDF_FILEWRITE*, FPDF_INCREMENTAL=1)` |
| Searchable PDF (optional) | `FPDFPageObj_CreateTextObj`, `FPDFText_LoadStandardFont`, `FPDFText_SetText`, `FPDFTextObj_SetTextRenderMode(INVISIBLE=3)`, `FPDFPageObj_Transform`, `FPDFPage_InsertObject`, `FPDFPage_GenerateContent` |
| Doc identity | `FPDF_GetFileIdentifier(doc, FILEIDTYPE_PERMANENT=0, buf, len)` |

Marshalling notes:
- `unsigned long` is 32-bit on Windows → `uint`.
- `FPDF_WIDESTRING` is UTF-16LE → `ushort*` / `char*`.
- `FPDF_BOOL` → `int`.

```
┌──────────────────────────────────────────────────────────────────────────┐

│ ┌──────────┐  │              │    pixel scrolling)   │                   │
│ │ thumb 2  │  │              └───────────────────────┘                   │
│   …           │                                                          │

└──────────────────────────────────────────────────────────────────────────┘
```

**Document view [built]**
- `ItemsControl` with `VirtualizingStackPanel` (`IsVirtualizing`, `VirtualizationMode=Recycling`, `ScrollUnit=Pixel`).
- Each item is a `Border` (white background, shadow) sized `PageViewModel.DipWidth × DipHeight`, containing an `Image` (`Stretch=Fill`) bound to `PageViewModel.Bitmap`.
- Container `DataContextChanged` / `Loaded` → `PageViewModel.OnRealized()` requests a render. `Unloaded` → `OnUnrealized()` cancels a pending render; the bitmap stays in `BitmapCache` (LRU, 200 MB).
- **Re-render rule:** a bitmap is stale when its pixel width differs from the target by > 2 %. The stale bitmap stays visible (stretched) until the new one arrives, so there's no flicker.
- **Zoom:** 10 %–800 %, step ×1.2. Ctrl+wheel zooms. After a zoom, `VerticalOffset` is scaled by `newZoom/oldZoom` to keep the reading position.
- **Fit width:** `(viewportWidth − 2·PageMargin − 24) / (maxPageWidthPt·96/72)`.
- **Fit page:** `min(fitWidth, (viewportHeight − 2·PageMargin) / (currentPageHeightPt·96/72))`.
- **Current page:** hit-test the viewport at (center X, 35 % height) and take the ancestor's `DataContext` as a `PageViewModel`.
- **Go to page:** `VirtualizingPanel.BringIndexIntoViewPublic(i)`, then `UpdateLayout`, then align the container top via `TransformToAncestor` + `ScrollToVerticalOffset`.

**Sidebar [built]**
- Thumbnails: `ListBox`, virtualized, 140 DIP wide, rendered at `Thumbnail` priority, kept on the view model (small).
- Chapters: `TreeView` bound to `OutlineNodeViewModel`; clicking an item goes to its page.

## 9. OCR design
- **Page OCR [built, basic]:**
  - Render at 300 DPI: `scale = 300/72`.
  - Clamp so max(w, h) ≤ `MaxImageDimension`.
  - `RecognizeAsync` → `TextWindow`.
- **Scanned detection [planned T-40]:** `GetCharCountAsync(page) < 8` ⇒ scanned. Show a banner: "This page has no text. [Run OCR] [OCR all pages]".
- **Background OCR [planned T-41]:**
  - A queue at `Background` priority, one page at a time, with progress in the status bar and a Cancel button.
  - Each result becomes a `PageTextLayer(Source=Ocr)`.
- **Cache [planned T-42]:**
  - Location: `%LocalAppData%\LitePDF\ocr\{docKey}.json`
  - `docKey` = hex of `FPDF_GetFileIdentifier`, or SHA-256 of (file length + first 64 KB + last 64 KB).
  - Schema:
    ```json
    { "version":1, "engine":"windows", "pages": { "3": { "lang":"en-US", "w":2550, "h":3300, "lines":[ { "words":[ {"t":"Hello","r":[l,t,r,b]} ] } ] } } }
    ```
- **Region OCR [planned T-43]:**
  - A "Select area" tool: drag a rectangle, render that clip at 300 DPI, OCR it, show a popup with Copy.
  - The popup also offers "Copy as image".
- **Images [planned T-44]:**
  - Open PNG/JPG/BMP/TIFF (decode with WPF `BitmapDecoder`, one page per frame) as an `ImageDocument : IPdfDocument`.
  - Ctrl+V on an empty workspace pastes and OCRs a clipboard image.
- **Languages [planned T-45]:** a picker listing `AvailableLanguages`, plus help text on installing OCR language packs.

## 10. Annotation design [planned T-50..T-56]

**Colors** (alpha 110)

| Name | RGB |
|---|---|
| Yellow | #FFE500 |
| Green | #7CE07C |
| Blue | #7CC7FF |
| Pink | #FF8AC8 |
| Orange | #FFB347 |

**Adding a highlight:**
1. Selection → `GetLineRects` → one quad per line (x1,y1 = top-left … x4,y4 = bottom-right in page points).
2. `FPDFPage_CreateAnnot`, append each quad, `SetColor`, `SetRect` (union).
3. PDFium generates the appearance when rendering.

**Saving:**
1. Write `FPDF_SaveAsCopy(INCREMENTAL)` to `file.pdf.litepdf-tmp`.
2. Close the source stream, then `File.Replace(tmp, file, null)`, then reopen. If `File.Replace` fails, keep the tmp file and report it.

**Dirty tracking:** show `*` in the title; ask Save / Don't save / Cancel on close.

**Export:** Markdown with `## Page N` headings and `- "text" (color)` items.

## 11. Persistence [planned T-60]
`%LocalAppData%\LitePDF\` contains:
- `settings.json`: `{ "theme":"system", "pageMode":"normal|dark|sepia", "defaultZoom":"fitWidth", "ocrLanguage":"en-US", "sidebarVisible":true }`
- `recent.json`: `[ { "path":"...", "docKey":"...", "page":12, "zoom":1.25, "opened":"2026-09-15T10:00:00Z" } ]` (max 20)
- `thumbs/`, `ocr/`: caches keyed by docKey. Deleting either is always safe.

## 12. Errors

| PDFium code | User message |
|---|---|
| 2 (File) | "File not found or could not be opened." |
| 3 (Format) | "This file is not a valid PDF or is damaged." |
| 4 (Password) | Prompt for a password (3 tries) |
| 5 (Security) | "Unsupported security handler." |

Render failures show a grey page with "Could not render page N". The app never crashes on a bad page: every worker call catches and wraps errors.
